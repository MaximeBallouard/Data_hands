# Data_hands

## Description
Jeu de données de mesures anthropométriques de la main (largeur et
longueur de la paume, longueur de l'index, du majeur et de l'annulaire)
permettant d'évaluer s'il est possible de distinguer les hommes des femmes
à partir de ces critères.

## Contenu
- `data/Mains_données_brutes.ods` : N = 81 participants (38 femmes, 43 hommes)

## Variables
| Colonne | Description | Unité |
|---|---|---|
| Taille index | Longueur de l'index entre le milieu du pli palmaire et l'extrêmité du doigt | mm |
| Taille majeur | Longueur du majeur entre le milieu du pli palmaire et l'extrêmité du doigt | mm |
| Taille annulaire | Longueur de l'annulaire entre le milieu du pli palmaire et l'extrêmité du doigt | mm |
| Largeur paume | Largeur de la paume au niveau des extrêmités des plis de flexion de la paume | mm |
| Longueur paume | Longueur de la paume entre le milieu du pli du poignet et le milieu du pli palmaire du majeur | mm |
| sexe | F ou H | - |
| Adulte | l'individu est-il adulte ? (>= 18 ans) Oui ou Non | - |
| Type de mesure | Mesure directe à l'aide d'un pied à coulisse sur la main, doigts tendus ... OU ... Mesure sur main négative ... OU ... Mesure sur main positive | - |

## Protocole de mesure
(instrument, repères anatomiques, posture, précision)
Les mesures ont été effectuées à l'aide d'un pied à coulisse permettant de donner une mesure précise au dixième de millimètre, sur des mains aux doigts tendus ou des mains négatives/positives à la manière des représentations préhistoriques. Les mesures ont été effectuées entre les différents plis palmaires cités dans la description des variables.
